Authority chain model

Principal / identity → Role → Capability → Policy authority → Approval → Preflight → Action → Result → Independent verifier

Integrity checks

Future validator: event ID uniqueness, previous-hash continuity, canonical event hash, source revision, timestamps, producer identity, and independent verifier evidence.

Integrity caveat

A hash chain can expose certain changes. It does not authenticate the creator or prevent a privileged actor from rewriting every copy.
