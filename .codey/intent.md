# I-hub-tabs-unify: Promote More pages to nested hub tabs and unify governance masters

## Goal
Turn the swarm hub into a nested tabbed current-state reference: interactive role map, authority and responsibility review, governance inputs/outputs review, observatory, and every remaining More page become tabs with the same behaviour as existing hub tabs; unify the two governance master reports into one document; remove redundancies; auto-update what can be derived from allowlisted governance sources; keep refresh_and_push and Pages deploy working; review nexus-aquarium read-only.

## Acceptance Criteria
- AC-1: Interactive role map, authority/responsibility review, governance I/O review, and observatory are reachable as hub tabs (not only as More links), with the same ARIA tablist/tabpanel, hash routing and keyboard behaviour as the existing top-level tabs.
- AC-2: Every former More page (governance masters, workspace map, R-054, rulings in force, rulings annex) is also a hub tab (top-level or nested), and the More catch-all list is gone or reduced to nothing material.
- AC-3: The two governance master HTML reports are unified into a single published document with no unique content lost and duplicated overlapping content removed; hub links point only at that single document.
- AC-4: Related tabs are nested under a small top-level set (Overview, Governance, Bots, Observatory, Assistant, Workspace or equivalent); nested switching works with hash deep-links.
- AC-5: Functionality holds: top and nested tab switching, charts on Bots, observatory internal tabs via its page, local links resolve; `python3 scripts/validate_observatory.py` passes; `scripts/refresh_and_push.sh` still builds data/ only without error when gitleaks is present.
- AC-6: Where practical, published facts are regenerated by allowlist fail-closed build scripts from `/workspace/governance` (pattern of `scripts/build_review_data.py`: no secrets, personal data, BIE or gambling data); remaining dated copy is manually aligned to current governance sources; homepage describes current state only.
- AC-7: Branch PR opened as gemquota; `/tmp/gitleaks` finds nothing on the branch; a separate fresh-context verifier marks each AC PASS/FAIL/UNVERIFIED with evidence; after PASS and clean scan, PR is merged; every write logged in `/workspace/governance/github-log.md` with bot=Engineer account=gemquota; live Pages URLs return HTTP 200 after deploy.
- AC-8: Nexus aquarium is identified and reviewed read-only (what it is, state, whether it works, live link, issues) with no changes made to it.

## Scope
- `/workspace/swarm-site` (gemquota/swarm)
- Logging line appends to `/workspace/governance/github-log.md`
- Read-only review of gemquota/nexus-aquarium and related workspace paths

## Out of Scope
- Changing nexus-aquarium code or deploy
- Force-push, visibility/settings changes, deleting files outside the task diff
- Reading or printing secrets or gitignored credential files
- Publishing private identity/BIE/gambling content beyond what is already carefully handled
