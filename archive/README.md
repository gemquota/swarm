# Site archives

Dated frozen copies of the swarm hub, served by GitHub Pages under `/archive/<date>/`.

## Layout

- `2026-11-03/` — immutable freeze of the hub at tag `archive/swarm-site-2026-11-03`. **Do not modify.**
- `MANIFEST-2026-11-03.sha256` — SHA-256 manifest of that freeze (kept *beside* the freeze directory so the freeze tree stays byte-stable).
- `reviews/` — dated governance review HTML moved out of the live root (`governance/reviews/`). Old URLs redirect here. Nothing was deleted outright.
